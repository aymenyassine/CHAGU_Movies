# CHAGU Movies

Application web de catalogue de films : recherche de films, ajout de commentaires et gestion de profil utilisateur, développée en PHP et JavaScript.

## Fonctionnalités

- Authentification (inscription, connexion, déconnexion)
- Recherche et affichage de films
- Ajout et suppression de films
- Commentaires sur les films
- Gestion du profil utilisateur (photo, informations) avec envoi d'email

## Stack technique

- PHP (logique serveur et API)
- JavaScript, HTML, CSS (frontend)
- MySQL

## Lancer le projet

1. Importer `mysql sever.session.sql` dans une base MySQL
2. Configurer les identifiants de connexion à la base de données dans les fichiers PHP
3. Servir le projet avec un serveur PHP local (ex : `php -S localhost:8000`) ou via XAMPP/WAMP

## Contexte

Projet réalisé pour s'exercer au développement web full-stack en PHP natif (sans framework).
